# 密匣 · 本地密码保险箱

一个只跑在你电脑上的账号密码管理器。没有服务器、没有注册、不联网。
你的密码加密后存在本机的 `data/vault.json` 里，加解密全部在浏览器里完成。

---

## 一、怎么打开

双击目录里的 **`启动密匣.vbs`**（没有黑窗口，推荐）。

如果系统不让你运行 `.vbs`，改双击 **`启动密匣.bat`**（会留一个黑色命令行窗口，别关它——
关掉窗口就等于关掉保险箱）。

浏览器会自动打开 `http://127.0.0.1:8765/`。

- 第一次用：设置一个主密码，页面会显示强度提示。
- 以后每次打开：输入这个主密码解锁。

> 前提：这台电脑装了 Python 3.9 或更新版本。命令行里输入 `python --version` 能打印出版本号就行。
> 安装 Python 时记得勾选 **Add Python to PATH**，否则启动脚本找不到它。

---

## 二、主密码这件事，请先读

**主密码不会被存在任何地方，也没有「找回」按钮。**

打开保险箱时，程序用你的主密码派生出解密钥匙（PBKDF2-SHA256，60 万轮），
拿这把钥匙去解 `data/vault.json` 里的密文。主密码错了，谁也解不开——包括我。

所以：

- 挑一句**又长又好记**的话，比如「阳台的薄荷今年开了三次花」，比 `Xy7!q2` 这种短密码安全得多。
- **把它抄在纸上，放在家里**。别只记在脑子里，也别存进这个保险箱自己里面。
- 真的忘了：数据还在，但内容取不回来了。这时候你只能靠之前导出的备份 + 那个备份的主密码。

## 三、界面怎么用

| 想做什么 | 怎么做 |
| --- | --- |
| 记一个新账号 | 右上角「新建」，或按 `Ctrl N` |
| 找一条 | 顶部搜索框，或按 `Ctrl K`；按名称、账号、网址、标签都能搜 |
| 复制密码 | 打开条目，点密码条右侧的复制图标 |
| 看密码 | 密码条右侧的眼睛图标，再点一次藏起来 |
| 按分类看 | 左侧「分类」里的条目 |
| 只看收藏 | 列表上方「只看收藏」，或用详情页的收藏图标打标记 |
| 生成随机密码 | 右上角「⋯」→「密码生成器」，或在编辑条目时点密码框右侧的「生成」 |
| 上锁 | 右上角「锁定」，或关掉浏览器标签页 |

复制的密码会在 **30 秒后自动从剪贴板清掉**（前提是这 30 秒内剪贴板没被别的东西覆盖）。
清理时右下角会提示「剪贴板已清空」。

## 四、数据在哪，怎么备份

```
password-vault/
├─ data/
│  ├─ vault.json          ← 你的密码（密文）
│  └─ backups/            ← 每次改动前自动留的密文备份，最多 40 份
```

- 右上角「⋯」→「打开数据文件夹」可以直接跳到这个目录。
- 「⋯」→「立即备份密文」会马上复制一份带时间戳的备份。
- **备份方式**：把整个 `data` 文件夹拷到 U 盘或网盘即可。它里面只有密文，没有主密码就解不开。
- **换电脑**：把整个 `password-vault` 文件夹（或者至少 `data/vault.json`）拷过去，
  装好 Python，双击启动，输入原来的主密码就能用。

## 五、导入 / 导出

「⋯」→「导入」支持三种文件：

1. **密匣自己的加密备份**（`.mihsia.json`）—— 需要输入那份备份当时的主密码。
2. **别的工具导出的 JSON** —— 只要里面是条目数组，会自动认字段。
3. **CSV** —— 表头能认中英文（`name/名称`、`username/账号`、`password/密码`、`url/网址`、`notes/备注`）。

导入时可以选择「同名条目」怎么处理：保留我的跳过重复 / 覆盖 / 两条都留。

「⋯」→「导出」有两种：

- **加密备份**（推荐）：导出一个 `.mihsia.json`，仍然是密文，可以安全地放进网盘。
- **明文 CSV**：所有密码都是明文，只有在迁移到别的密码工具时才用，导完请立刻删掉。

## 六、它到底安全在哪

**做得对的：**

- 只监听 `127.0.0.1`，外面连不进来。
- 每次启动生成一次性访问令牌，注入页面；其他网页即使猜到端口也读不到数据。
- 校验 `Origin`，挡住别的网站在你浏览器里偷偷发请求。
- 加解密全部在浏览器里，用 WebCrypto 的 AES-256-GCM；**服务端经手的只有密文**。
- 落盘用「临时文件 + fsync + 原子替换」，不会写到一半把保险箱写坏。
- 页面设了严格 CSP，禁止内联脚本和外部资源。

**必须坦白说明的：**

- 保险箱打开期间，解密后的密码就在浏览器内存里。如果这台电脑中了木马，木马能读到它。
  再好的密码管理器也挡不住这个。
- 本工具**不防**已经拿到你系统管理员权限的攻击者。它的目标是：别让密码躺在明文
  记事本和聊天记录里，别让密码在多个网站重复使用。
- 主密码强度直接决定密文强度。一句 6 位短密码配上 60 万轮 PBKDF2，也只是拖时间。

## 七、常见问题

**浏览器没自动打开？**
照着手动访问 `http://127.0.0.1:8765/`，或者看命令行窗口里打印的地址（端口被占用时会自动换一个）。

**第一次打开是什么样？**
会看到一个「建立保险箱」的表单，让你设主密码。设完就进主界面，可以从零开始录。
想先看看装满数据时长什么样，`shots/` 里有 8 张界面截图。

**能改主密码吗？**
界面上暂时没有「改主密码」按钮。要换的话走这条：
「⋯」→「导出」→ 加密备份 → 删 `data/vault.json` → 重新建立保险箱（设新主密码）
→ 「⋯」→「导入」那份备份（输**旧**主密码）。导完之后数据就用新主密码加密了。

**端口 8765 被占了？**
程序会自动挑一个空闲端口，地址以命令行窗口打印的为准。

**关掉窗口又重开，浏览器里那个旧标签页报错？**
标题里的「密匣」每次启动都会换一把一次性钥匙，旧标签页手里的钥匙就作废了。
关掉旧标签页，用新打开的那个就行——数据一点没丢。

**提示「主密码不对」？**
先确认大写锁定和输入法。如果确定没打错，那就是主密码记岔了——这个文件已经解不开了，
用备份文件恢复（备份也需要它自己那一刻的主密码）。

**能放到手机上用吗？**
不能，这是桌面本地工具。设计上就不打算把保险箱挂到网络上。

**会不会偷偷上传？**
不会。整个项目就一个 Python 文件加三个前端文件，你可以自己翻一遍：
`vault_server.py` 除了连接本机 `127.0.0.1` 之外，没有任何往外发的请求。

## 八、文件清单

```
password-vault/
├─ 启动密匣.vbs        推荐：无窗口启动
├─ 启动密匣.bat        备用：带命令行窗口启动
├─ vault_server.py     本地服务（只用 Python 标准库）
├─ web/
│  ├─ index.html       页面结构
│  ├─ app.css          样式
│  └─ app.js           加解密与全部交互逻辑
├─ data/               你的数据（运行时生成）
├─ tools/              开发者用的自测脚本，可删
└─ shots/              界面截图，可删
```

不需要 `pip install` 任何东西，也不需要 Node.js。
